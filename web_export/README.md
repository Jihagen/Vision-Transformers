# Website data

Everything the project website plots comes from this folder. The files here are
generated by `scripts/export_web_data.py` from saved experiment outputs under
`results/`; no value is typed in by hand.

All exports are currently marked **preliminary**: the thesis is in progress and
the underlying experiments are single runs (see `STATUS.md`).

## Regenerating

```bash
python scripts/export_web_data.py           # rewrite web_export/data and the manifest
python scripts/export_web_data.py --check   # validate sources, write nothing
```

The script needs `numpy` and `pandas` (both in `env.yml`) and runs in a few
seconds. It needs neither the model nor a GPU nor any source image.

`results/` is not version-controlled (it is about 100 GB), so the export can only
be regenerated on a machine that holds the saved experiment outputs. That is why
the generated files are committed. An export whose source files are missing is
skipped and listed under `skipped` in the manifest; it is never filled with
placeholder values.

## Metadata

Each table `<name>.csv` has a sidecar `<name>.meta.json`; each `.json` export
carries the same block under `meta`. The block states:

- `sources`: the saved result files the export was read from
- `model`, `model_config`: model identifier and the experimental configuration
- `feature_labels`: what the contrasts, directions or tasks are
- `units`, `aggregation`: what each column measures and how it was aggregated
- `status`: `preliminary` or `final`
- `caveats`: limitations a figure caption should not hide

A figure on the website should show the `status` and take its caption caveats
from this block.

## Manifest

`release_manifest.json` records the generation time, the git commit of the code,
the model identifier and checkpoint configuration, every source file with its
SHA-256, size and modification time, the list of exports, and which of them are
preliminary. Because `results/` is not in git, the hashes are what ties an export
to a specific set of experiment outputs.

The model revision is recorded as unknown: the experiments ran from a local
snapshot of the checkpoint and the Hub commit it was downloaded from was not
logged.

## What is deliberately not here

- No source images and no per-image records from the evaluation datasets
  (see `DATA.md`).
- No activations, direction vectors or trained perturbations.
- Nothing that exists only as a notebook cell output or a rendered figure. Those
  results are listed in `STATUS.md` and enter the export once the notebook writes
  them to a table.
